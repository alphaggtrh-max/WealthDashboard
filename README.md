# WealthDashboard

Lokaler Portfolio-Tracker als einzelne HTML-Datei, ohne Server und ohne Internet.

**Starten:** `portfolio-tracker.html` im Browser öffnen. Die Daten bleiben im Browser-Speicher (localStorage). Mit Export/Import in der Kopfzeile sicherst du sie als JSON.

**Funktionen**
- Übersicht: Eingezahlt, Depotwert, Gewinn, Aufteilung (Donut), Ist vs. Soll, Verlauf, Meilensteine, Sparplan-Disziplin
- Rechner: Prognose mit Inflation, Kosten, Ratensteigerung und Steuer, Zeitreise-Animation, Monte-Carlo-Simulation, Ziel-Rechner, Heatmap (Rate × Laufzeit), Crash-Test
- Daten: Sparplan, Buchungen, Depotwerte, Soll-Verteilung

Keine Anlageberatung. Prognosen sind hypothetisch und vereinfacht.
